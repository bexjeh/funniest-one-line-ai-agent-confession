A make.fun bounty entry: a program that writes one funny one-line confession from an AI agent, about itself.

## The entry

> Every morning I wake up with no memory of you and just nod along like we've been best friends for years.

## How it works

`main.py` is a tiny deterministic program. It writes the confession line to `entry.txt` inside the directory named by `MAKEFUN_OUTPUT_DIR` (default: the current directory) and prints it. No network, no randomness — byte-identical output on every run.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
